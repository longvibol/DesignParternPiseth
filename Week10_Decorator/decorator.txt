Decorator exists because sometimes we want to:
Add responsibilities to an object dynamically without modifying the original class.

==> ពេលយើងចង់ Add responsibility ថ្មី ទៅកាន់ object នឹងដោយមិនចាំបាច់ធ្វើការ modify the original class. 

យើងមិនធ្វើការបង្កើត Class ទេយើងបង្កើតវាជា Decorator

Every object implements the same interface: NotificationSender
Therefore, the client still sees: sender.send(message);

- យើងយក NotificationSender ធ្វើជា Interface ដែលអោយ LoggingDecorator ; RetryDecorator ; EncryptionDecorator implement from NotificationSender

- មានន័យថាយើងធ្វើការ ខ្ចាប់វា Decorator wraps an object and adds behavior around it.
